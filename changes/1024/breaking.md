- Layers inside component instances have Figma's IDs, `I<instance>;<layer>;…`, named after the outermost instance and the component layers down to them, in the plugin API, MCP and AI tools, and `@open-pencil/scene-graph`. Their overrides are recorded on the outermost instance by layer path: `InstanceOverrideState` holds `self` and `layers` instead of `descendants`, `getInstanceOverride`, `setInstanceOverride`, `hasInstanceOverride`, and `deleteInstanceOverride` take a layer path instead of instance and layer IDs, and a copy no longer links to its component layer through `componentId`, which now only names the component an instance shows. Use `overrideTarget`, `setLayerOverride`, and `instanceLayerSource` to find a layer's owner, record an override, or read the layer it copies. Stored library revisions and rooms saved in the earlier shape are converted when opened, and `migrateInstanceLayers` converts other graphs.
